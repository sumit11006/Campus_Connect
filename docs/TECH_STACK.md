# Tech Stack

## Mobile Application (Flutter)
- **Framework**: Flutter (Dart)
- **State Management**: flutter_riverpod, riverpod_annotation
- **Routing**: go_router
- **Networking**: dio
- **Storage**: shared_preferences, flutter_secure_storage
- **UI/Styling**: google_fonts, cached_network_image, shimmer, flutter_animate
- **Other**: socket_io_client (Chat), image_picker

## Admin Panel (React)
- **Framework**: React 18
- **Build Tool**: Vite
- **Routing**: react-router-dom
- **Networking**: axios
- **Icons**: lucide-react

## Backend (Node.js)
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (Mongoose ORM)
- **Authentication**: JWT, bcryptjs
- **Real-time**: Socket.IO
- **File Uploads**: Multer
- **Security & Utils**: helmet, cors, dotenv, morgan, express-validator
- **Testing**: Jest, Supertest
