# Design System: Premium Modern Campus

## 1. Color Palette

**Primary Colors**
- Primary: `#7C3AED` (Vibrant Purple)
- Secondary: `#EC4899` (Energetic Pink)
- Accent: `#FAB74A` (Warm Yellow/Gold)

**Surface & Backgrounds (Admin - Glassmorphism Theme)**
- Background (Dark): `#0F1627` to `#10182A` gradient
- Surface / Cards: `rgba(255, 255, 255, 0.05)` with blur
- Border: `rgba(255, 255, 255, 0.1)`

**Surface & Backgrounds (App - Light/Premium Theme)**
- Background: `#F8FAFC`
- Surface: `#FFFFFF`
- Surface Variant: `#F1F5F9`

**Text Colors**
- Text Primary (Dark Theme): `#F0F2F6`
- Text Secondary (Dark Theme): `#C2C8D5`
- Text Primary (Light Theme): `#0F172A`
- Text Secondary (Light Theme): `#64748B`

**Semantic Colors**
- Success: `#10B981`
- Warning: `#F59E0B`
- Error: `#EF4444`
- Info: `#3B82F6`

## 2. Typography

**Font Family**: `Outfit` (Headings) / `Inter` or `Roboto` (Body)

- **Display**: 48px, Bold, -0.04em tracking
- **H1**: 32px, Bold, -0.02em tracking
- **H2**: 24px, SemiBold
- **H3**: 20px, Medium
- **Title**: 18px, Medium
- **Body Large**: 16px, Regular
- **Body**: 14px, Regular
- **Body Small**: 12px, Regular
- **Caption**: 10px, Medium, Uppercase (Tracking: 0.08em)

## 3. Spacing System (8pt Grid)
- 4px
- 8px
- 12px
- 16px
- 20px
- 24px
- 32px
- 40px
- 48px
- 64px

## 4. Border Radius
- **Small**: 4px (Badges, tags)
- **Medium**: 8px (Inputs, small buttons)
- **Large**: 16px (Cards, dialogs)
- **XL**: 24px (Hero cards, bottom sheets)
- **Pill**: 9999px (Primary action buttons, chips)

## 5. Shadow System
- **None**: For flat/contained UI
- **Subtle**: `0 2px 8px rgba(0,0,0,0.05)` - standard cards
- **Medium**: `0 8px 24px rgba(0,0,0,0.08)` - dropdowns, hovering cards
- **Floating**: `0 20px 40px rgba(0,0,0,0.12)` - modals, bottom sheets, FABs
